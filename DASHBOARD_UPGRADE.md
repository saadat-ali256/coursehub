# CourseHub Dashboard Upgrade

- Responsive student dashboard with working Overview, My Courses, Subscriptions, Progress, Profile and Settings tabs.
- Premium/free membership indicator based on active subscription records.
- Admin Dashboard button for admin users and User Dashboard return button in admin workspace.
- Home page now has an Admin-pinned/Featured Courses section.
- Admin Course CMS already exposes Featured as the pin control.
- Admin exports: Users Excel and Subscriptions Excel from the admin header/Course CMS.
- Admin analytics now includes a six-month subscription revenue/value bar chart.
- Password change, profile editing, learning goals, notifications, certificates, bookmarks, quiz performance and progress are surfaced in the dashboard.
- Layout is responsive for phone, tablet and desktop.

Note: the exported `.xls` files use Excel-compatible SpreadsheetML so they open directly in Microsoft Excel without adding another runtime dependency.
